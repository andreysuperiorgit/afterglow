# AFTERGLOW

An endless 80s anime drive into the night. Built with Opus 5.5.

One HTML file, no game engine, no 3D models: the car, traffic, palms, neon, sky and ocean are all code (three.js).

**Play:** https://andreysuperiorgit.github.io/afterglow/

Controls: arrows / WASD to drive, SHIFT nitro (close calls fill it), C camera, P photo mode, M sound. On phones: hold the left or right half of the screen to steer, two fingers to brake, N2O button for nitro.

Sound: real Corvette Z06 recordings (start, idle, high revs), no synthesizer.
